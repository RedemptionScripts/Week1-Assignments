# Task 3 - CSS Challenge

A practical CSS challenge demonstrating modern CSS layout and animation
techniques.

## 1. Flexbox Challenge

The Flexbox section contains three feature cards.

### Demonstrated concepts

-   `display: flex`
-   `justify-content`
-   `align-items`
-   `gap`
-   Flexible card widths
-   Hover effects
-   Responsive layout

On desktop, the cards are displayed horizontally. On smaller screens,
the cards stack vertically.

## 2. CSS Grid Challenge

The Grid section contains multiple dashboard-style items.

### Demonstrated concepts

-   `display: grid`
-   `grid-template-columns`
-   `repeat()`
-   Grid column spanning
-   Grid row spanning
-   Responsive grid layout
-   Equal spacing
-   Card styling

The project contains more than the required six grid items.

## 3. Animation Challenge

The animation section demonstrates:

-   Button hover animation
-   Loading spinner
-   Fade-in animation
-   Card lift effect
-   Animated navigation underline

The animations use CSS transitions, transforms, and keyframes.

### Technologies

-   HTML5
-   CSS3
-   JavaScript

2.  Open the project folder in Visual Studio Code.
